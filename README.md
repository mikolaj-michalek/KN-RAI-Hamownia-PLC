# KN-RAI-Hamownia-PLC
Repozytorium projektu w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Projekt dotyczy modernizacji stanowiska hamowni w system oparty o ideę Przemysłu 4.0. Zakłada on dodanie czujników temperatury i drgań, pomiar oraz wizualizację mocy w czasie rzeczywistym poprzez sterownik PLC i panel HMI.
